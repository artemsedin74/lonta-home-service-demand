# Editorial assets for the Home-Service Demand Study

[Download the editorial kit ZIP](https://github.com/artemsedin74/lonta-home-service-demand/releases/download/editorial-kit-v1/lonta-home-service-demand-editorial-kit-v1.1.zip)
or [read the release notes](https://github.com/artemsedin74/lonta-home-service-demand/releases/tag/editorial-kit-v1).

Three reporting angles, four figures and the underlying aggregate tables from
[Lonta AI's Home-Service Demand Study](https://lonta.io/research/home-service-demand/).
Prepared October 15, 2026. The research remains version 1.0; this kit adds reuse
instructions and claim-to-source references, not new survey results.

For a quick read, use the [two-page editor brief](lonta-home-service-demand-editor-brief-v1.pdf). [EMBEDS.md](EMBEDS.md) provides copyable image/caption HTML with source context. Version 1.1 adds these materials and a separate blank capacity workbook; the original v1 ZIP is retained unchanged. The four `embed-*.html` files preview with local images after unpacking, without a hotlink dependency.

Start with [SOURCE-BRIEF.md](SOURCE-BRIEF.md). Choose one finding that answers your
readers' question. [CAPTIONS.md](CAPTIONS.md) supplies a caption, alt text and data
location for each figure. [source-claims.csv](source-claims.csv) maps the selected
numbers to the precise fields in the public aggregate JSON.

The downloadable kit contains PNG and editable SVG versions of the four figures,
three aggregate CSVs, aggregate JSON, these notes and a checksum manifest. The
[complete repository](https://github.com/artemsedin74/lonta-home-service-demand)
also contains the calculation code and input instructions. Raw household and
project records are excluded from both the repository and kit.

This is company-authored source material prepared with OpenAI Codex. Editors can
inspect it and decide independently whether and how to cover it. It is a public,
nonexclusive resource, not an exclusive guest manuscript or a claim of peer review.
Follow your publication's AI/source policies. Permission to reuse these assets
does not establish that a manuscript meets those policies.

For a story, link to the canonical report and identify the original survey and
the archival edition used. [SOURCES-AND-RIGHTS.md](SOURCES-AND-RIGHTS.md) gives the
credit line and licenses. Keep the population, time window and professional-work
definition with each finding. Preserve the figure footer when reproducing an image;
if you redraw it, carry those notes into the adjacent caption.

The associated [service-mix worksheet](../service-mix-worksheet.txt) helps a business
owner turn a national pattern into a local question. The survey does not supply
local advertising returns, current prices or a contractor's margin.
